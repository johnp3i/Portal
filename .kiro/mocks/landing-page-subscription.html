🔧 Integration with Existing Login

The landing page lives at portal.3inventors.com/ (root). The existing login page stays at /Account/Login. The routing logic:

portal.3inventors.com/ → Unauthenticated? Show landing → Sign In clicked → /Account/Login → Authenticated → /Dashboard
Get Started clicked → /Account/Register?plan=X → Stripe Checkout → Webhook → Create Business → Setup Wizard

Existing users who visit / while authenticated are redirected straight to /Dashboard. The login page design stays exactly as-is — the particle canvas and form panel are untouched.
