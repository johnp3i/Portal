# Quotation Platform Production Pack

This pack contains a coherent HTML screen set for the MyChair quotation platform.

Included screens:
- quotation_dashboard.html
- quotation_list.html
- create_quotation.html
- quotation_detail.html
- convert_quotation_to_invoice.html
- invoice_list.html

Purpose:
- demo the quotation workspace
- support KIRO handoff
- validate UI flow before implementation

Important product decision:
Quotation-to-invoice conversion is treated as a first-class workflow.
A quotation should be convertible only after acceptance and billing validation.
