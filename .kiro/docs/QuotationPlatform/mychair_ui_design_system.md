# MyChair UI Design System (Product-Level Specification)
Version: v1.0  
Purpose: Ensure consistent UI/UX across all MyChair platforms (POS, ERP, OPS, JDS, Insights, Quotation Engine)

---

## 1. Design Philosophy

MyChair is NOT a generic SaaS UI.

It represents:
- Operational backbone
- Financial awareness
- Structured execution
- Future intelligence readiness

### Core Principles
1. Clarity over decoration
2. Operational seriousness
3. Consistency across modules
4. Signal-first UI (not noise)
5. Trust through structure

---

## 2. Visual Identity

### Color System

Primary:
- Blue: #0D5EA6
- Dark Blue: #0B4E89
- Accent Cyan: #57B8E8

Semantic:
- Success: #129867
- Warning: #C8912E
- Danger: #C24A4A

Background:
- Base: #F7FAFC
- Secondary: #EEF4F8

### Usage Rules
- Blue = structure / control
- Green = positive financial outcome
- Red = risk / overdue
- Gold = partial / attention

---

## 3. Layout System

### Structure
- Sidebar (fixed navigation)
- Topbar (context + actions)
- Content grid

### Grid Rules
- KPI → 4-column grid
- Sections → 2-column grid
- Forms → 2-column grid

### Spacing
- Section gap: 20–24px
- Card padding: 20–24px

---

## 4. Components

### Cards
- Border radius: 20–30px
- Soft shadow (NOT heavy)
- Light gradient background

### Buttons
- Primary → Blue gradient
- Secondary → White with border
- Success → Green

### Tables
- Clean rows
- No heavy borders
- Clear financial columns

---

## 5. Typography

- Headings: Manrope-style (bold, tight)
- Body: Inter
- Emphasis: Numbers > text

---

## 6. Interaction Rules

- No visual noise
- Actions always visible
- Financial states auto-calculated (never manual)

---

## 7. Product Alignment

### Applies to:
- POS Admin
- ERP
- OPS / OMS
- JDS
- Insights
- Quotation Engine

---

## 8. Anti-Patterns (Strict)

DO NOT:
- Use startup flashy gradients
- Overuse colors
- Add unnecessary animations
- Mix design styles

---

## 9. Future Alignment

This system must evolve toward:
→ Intelligence Platform UI

---

## 10. Implementation Notes

- Use reusable components
- Keep CSS tokens centralized
- Maintain consistent spacing + radius
