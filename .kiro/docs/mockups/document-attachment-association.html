Design Notes

Visual Association Cues:

  • 3px left-border accent (#0D5EA6) on the attachments panel reinforces "belongs to" relationship
  • Contextual label "Documents attached to this purchase/invoice" makes the relationship explicit
  • "Unlink" action (not "Delete") makes clear that removing only breaks the association — the file remains in the library
  • "Attach from library" button allows linking existing documents without re-uploading

List View Indicators:

  • Paperclip icon + count badge provides quick scan of attachment status
  • Rows without attachments show a subtle dash — no visual noise
  • Badge is clickable (in implementation) to jump straight to the attachments panel

Verified Badge:

  • Used for signed documents or externally validated files
  • Green color matches the success palette token
  • Positioned inline with the filename for immediate visibility
