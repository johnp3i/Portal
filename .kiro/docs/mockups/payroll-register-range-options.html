D. Percentage values - where they appear

The raw payslip deduction line already carries its rate (e.g. SI 8.80%), so this is a display-only add.

  • Detail sheet: a "%" column on every Employee Deduction and Employer Contribution line (shown in B1/B2 above). Earnings have no rate, so their % cell is blank/"-".
  • Summary sheet: percentages are per-line rates, not per-employee, so they fit most naturally on the contribution-totals block (C2) or as a small "% of gross" helper. If you pick C1 (per-type columns), the % would show once in the header note rather than per cell. Tell me which you prefer.
A rate can change mid-range (rate history). If an employee's SI rate changed in, say, July, the detail "%" for that line would show the most recent rate in the range, with the amounts still summed correctly. Flagging this so we agree on how to show a changed rate.
