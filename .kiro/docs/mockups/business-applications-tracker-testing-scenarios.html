QA · Compliance Filings

Business Applications Tracker — Testing Scenarios

Step-by-step testing guide for QA engineers. Open in browser, follow each scenario, and check off steps as you go.

Difficulty: Quick Moderate Complex

Prerequisites

  • ☐ SQL Server running with Portal database accessible
  • ☐ Application deployed and running (Development or Staging environment)
  • ☐ SuperAdmin account credentials available
  • ☐ At least 2 tenant businesses set up (Business A, Business B)
  • ☐ Professional-tier subscription active on Business A
  • ☐ Foundation-tier subscription active on Business B (for gating tests)
  • ☐ Enterprise-tier subscription on a third business (optional, for tier verification)
  • ☐ Test PDF files: valid-small.pdf (<1MB), valid-5mb.pdf (exactly 5MB), oversized.pdf (6MB), test.docx
  • ☐ Browser DevTools accessible for network inspection

Database Setup & Seed Verification

Quick

Steps

Expected Results

  • 4 categories: Tax, Employee, Regulatory, Business Registration
  • 5 templates: Social Insurance Monthly, VAT Return Quarterly, IR7 Annual, Employer's Declaration, Annual Levy

02

SuperAdmin Template Management

Moderate

Steps

Expected Results

  • Template CRUD operations work with proper BlockUI + SweetAlert2 feedback
  • Deactivation uses SweetAlert2 confirmation dialog (not native confirm)
  • Deactivated templates are excluded from business-facing import list
  • All form fields validate (required fields, numeric constraints)

Edge Cases

  • Try creating a template with empty Name — should show validation error
  • Try DueDay = 32 — should reject
  • Try DueMonth = 0 or 13 — should reject
03

Category Management

Quick

Steps

Expected Results

  • 4 seeded categories visible on initial load
  • New category created successfully with BlockUI + SweetAlert2 flow
  • Edit persists name and description changes
  • Categories appear in template create/edit dropdowns

Edge Cases

  • Try creating a category with a duplicate name — should show error
  • Try empty name — validation should prevent submission
04

Template Import

Complex

Steps

    • Social Insurance Monthly → 12 records
    • VAT Return Quarterly → 4 records
    • IR7 Annual → 1 record
    • Employer's Declaration → 1 record
    • Annual Levy → 1 record
    • Total: 19 filings will be created

Expected Results

  • Preview correctly calculates total filing count (19)
  • Import creates all filings with correct due dates based on frequency
  • BlockUI shown during import, SweetAlert2 on completion
  • Redirect to filing list after successful import
  • All filings start with "Pending" status

Edge Cases

  • Duplicate import: Navigate back to /Compliance/Import, select same templates + year — system shows duplicate warning via SweetAlert2 and allows cancel
  • Import with no templates selected — Import button should be disabled
  • Selecting a past year — should still work (backfilling)
05

Filing List & Filters

Moderate

Steps

Expected Results

  • Pagination shows "Showing 1-15 of 19" on page 1
  • Category filter correctly narrows results
  • Status filter works independently and in combination
  • Date range filter respects DueDate field
  • Clear button resets all active filters

Edge Cases

  • Filter with no matching results — show "No filings found" empty state
  • Combine Category + Status + Date range — all three apply simultaneously
